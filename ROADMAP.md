# AutoNote — Приложение для учёта расходов на автомобиль

## Описание

Веб-приложение для ведения учёта расходов на автомобиль: топливо, ТО, ремонт, страховка, штрафы и прочие затраты. Позволяет отслеживать историю расходов, анализировать статистику и планировать бюджет на содержание авто.

## Стек технологий

| Слой | Технология |
|------|-----------|
| Frontend | React, TypeScript, Vite |
| UI | shadcn/ui + Tailwind CSS |
| Запросы | TanStack Query (React Query) |
| State | Zustand (для клиентского состояния) |
| Роутинг | React Router |
| Backend | NestJS, TypeScript |
| ORM | Prisma |
| БД | PostgreSQL |
| Auth | JWT (access + refresh tokens) |
| API | REST (возможен переход на GraphQL позже) |
